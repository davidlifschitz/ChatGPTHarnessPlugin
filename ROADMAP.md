# Roadmap

## M0 — architecture/documentation

The initial checkout contained only a product README. The M0 baseline is established by the M1 implementation and evidence documents in this branch.

## M1 — Hermes Runtime Adapter

Deliver a non-interactive product-side client that can resolve/connect to a configured Hermes runtime, submit a safe run, observe status/events, retrieve the result, and explicitly report unsupported capabilities.

## Later
